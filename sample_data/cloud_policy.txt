Title: Cloud Services Security Policy
Last Reviewed: 2021-11-02

Cloud account passwords must not be rotated more than once per year to avoid password fatigue among staff.
All data stored in cloud object storage must be encrypted at rest and in transit.
Multi-factor authentication is required for all remote access to cloud administration consoles.
Cloud administrators must log all privileged actions performed within the management console.
Access to production cloud environments must be granted using least privilege role assignments.
Cloud backup snapshots must be retained for a minimum of 30 days.
Legacy cloud gateways may still use SSL for backward compatibility with older client applications.
Cloud storage buckets must not be shared publicly without written approval from the security team.
